# いきづらい部！ 部員日誌

一個基於 Vue.js 3 和 Cloudflare Workers 的成員日誌應用程式，完整支援桌面版和手機版布局。

## ✨ 主要功能

- **完整響應式設計**：支援桌面版、平板版和手機版
- **成員篩選**：可依成員、年份、月份篩選推文
- **搜尋功能**：支援推文內容和成員名稱搜尋
- **自我介紹系統**：每個成員都有詳細的個人資料
- **日期導航器**：快速跳轉到特定日期的推文
- **主題切換**：支援明暗主題切換
- **推文互動**：點讚、分享功能
- **L高介紹**：主頁包含完整的L高介紹內容
- **手機版導航**：專為手機設計的橫向滾動導航

## 快速開始

### 1. 啟動後端服務

```bash
cd backend/worker
npm install
npm run dev
```

後端服務將在 `http://localhost:8787` 運行。

### 2. 啟動前端應用

```bash
cd frontend/page
npm install
npm run dev
```

前端應用將在 `http://localhost:5173` 運行。

### 3. 初始化資料庫

後端服務啟動後，資料庫會自動使用預設的成員和推文資料。

## API 端點

- `GET /api/members` - 獲取所有成員資訊
- `GET /api/tweets` - 獲取推文列表（支援篩選）
- `GET /api/stats` - 獲取統計資訊
- `POST /api/tweets` - 新增推文
- `POST /api/likes` - 處理喜歡/取消喜歡
- `GET /api/likes/status` - 獲取喜歡狀態

### 搜尋和篩選
- 全文搜尋
- 按成員篩選
- 按日期篩選

## 🔧 技術特點

- **前端**：Vue.js 3 Composition API、響應式設計、CSS 變數系統
- **後端**：Cloudflare Workers、SQLite (D1)、RESTful API
- **資料庫**：完整的成員和推文資料結構
- **樣式**：現代化 CSS、支援明暗主題、完整響應式設計
- **功能**：推文篩選、搜尋、日期導航、自我介紹系統

## 📱 響應式設計

- **桌面版**：三欄式布局（左側導航、中間時間軸、右側日期導航）
- **平板版**：隱藏右側日期導航，保持雙欄布局
- **手機版**：單欄布局，頂部手機版導航，橫向滾動成員選擇

## 🎨 主題系統

- **明暗主題**：支援自動切換和手動切換
- **成員主題**：每個成員都有獨特的品牌色彩
- **CSS 變數**：統一的設計系統和色彩管理

## 📊 資料結構

- **成員資料**：包含頭像、橫幅、個人資料、詳細資訊
- **推文資料**：支援內容、圖片、時間戳、作者關聯
- **互動資料**：點讚狀態、用戶偏好設定

## 🔍 搜尋和篩選

- **全文搜尋**：支援推文內容、成員名稱、Twitter ID 搜尋
- **多維篩選**：年份、月份、成員、點讚狀態
- **即時結果**：搜尋結果即時更新

## 📅 日期導航

- **年份選擇器**：快速切換不同年份
- **月份網格**：12個月快速選擇
- **日期列表**：顯示每天推文數量，支援點擊跳轉
